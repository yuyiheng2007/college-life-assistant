# 大学生活管理助手

一个运行在浏览器里的本地生活管理程序，不需要联网、不需要安装，数据全部保存在你自己电脑上。

## 怎么打开

双击 `index.html`（推荐用 Edge 或 Chrome 打开）。也可以把 `生活管理助手` 文件夹整体拷到 U 盘或换电脑继续用——但换电脑后数据不会自动跟随，需要先导出备份（见下方说明）。

## 功能一览

| 模块 | 功能 |
| --- | --- |
| 仪表盘 | 今日课程、今日待办、本月收支、本周健身次数、素材数量一屏总览 |
| 课表 | 周课表视图；已预填 26应智U(1) 一班课表；点格子可编辑/删除；支持周次、地点、老师、自定义颜色 |
| 日程规划 | 按日期看一天时间轴；课程自动标记为"占用"深色块；可添加学习/健身/社团/休息等安排 |
| 健身饮食 | 根据身高体重算每日热量目标（TDEE）；三套锻炼计划可切换、每日打卡；三餐+喝水打卡；体重记录 |
| 财务收支 | 月收入/支出/盈余/预算余额；支出分类统计；可设置每月生活费预算 |
| 待办事项 | 分「社团任务 / 组织任务 / 班级任务 / 小组任务 / 个人」五类；截止日期+优先级，逾期高亮 |
| Vlog 素材 | 图片/视频直接存进本机浏览器，可打标签、备注、搜索、播放 |
| 设置 | 自定义 12 个节次的开始时间（适配不同学校的作息） |

## 数据存哪

- 课表、日程、健身、财务、待办：存在浏览器 localStorage（首次打开会自动填入你的一班课表）。
- 图片/视频素材：存在浏览器 IndexedDB，不经过任何服务器。
- 注意：清空浏览器数据会清掉这些记录；换电脑/重装浏览器前请先备份。

## 备份方法

按 F12 打开开发者工具 → Console（控制台）粘贴下面代码回车，浏览器会下载一个备份文件：

```js
const d = JSON.parse(localStorage.getItem("college-life-assistant-v1") || "{}");
const a = document.createElement("a");
a.href = "data:text/json;charset=utf-8," + encodeURIComponent(JSON.stringify(d, null, 2));
a.download = "生活管理助手备份-" + new Date().toISOString().slice(0,10) + ".json";
a.click();
```

恢复：在 Console 粘贴下面代码（把文件内容替换成你的备份）：

```js
const backup = { /* 粘贴备份文件内容 */ };
localStorage.setItem("college-life-assistant-v1", JSON.stringify(backup));
location.reload();
```

## 常用建议

1. 每周日花 10 分钟：清空本周待办、看看财务盈余、排下周日程。
2. 每月 1 号：核对生活费预算，把上月的收支导出存档。
3. 素材拍了就传，打上标签（如"军训""食堂""图书馆"），剪视频时按标签找。
